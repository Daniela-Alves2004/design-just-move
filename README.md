# Just Move — protótipo

Protótipo navegável do app **Just Move** (fisioterapia gamificada), exportado do Claude Design.

## Ver online

https://daniela-alves2004.github.io/design-just-move/

## Páginas

| URL | Conteúdo |
|-----|----------|
| `/` | Protótipo navegável (onboarding → hub → lista → sessão → resultado) |
| `/prototype.dc.html` | Mesmo protótipo |
| `/exploration.dc.html` | Exploração visual (direções A / B / C) |
| `/screens.dc.html` | Telas em formato documento/PDF |

## Como navegar

No celular do protótipo: toque nos botões da interface. A sessão avança as repetições sozinha. Use os atalhos à esquerda para reiniciar no onboarding ou ir ao hub.

## Local

```bash
npx serve .
```

Abra `http://localhost:3000` (ou a porta que o `serve` indicar).

## GitHub Pages

No repositório: **Settings → Pages → Source: Deploy from a branch → Branch: `main` → folder: `/ (root)`**.
